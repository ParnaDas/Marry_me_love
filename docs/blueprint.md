# **App Name**: Marry Me, Love

## Core Features:

- Proposal Message Display: Clearly display the romantic proposal question to the user.
- Interactive Choice Buttons: 'Yes' and 'No' buttons for responding to the proposal.
- Dynamic Button Scaling: On each 'No' press, the 'No' button will visually shrink, and the 'Yes' button will visually enlarge, engaging the user with the choices.
- Forced Acceptance Logic: After a predefined number of 'No' presses (e.g., 5 times), the 'No' button will disappear, making the 'Yes' button the only visible option and greatly increasing its size.
- Celebration on 'Yes': Trigger a celebratory visual animation (e.g., confetti or sparkles) when the 'Yes' button is pressed.

## Style Guidelines:

- Background color: A deep, rich charcoal with a hint of red to set a romantic, intimate mood. (HEX: #2F2126)
- Primary color: A luxurious, slightly desaturated crimson red, embodying passion and love, used for prominent text or highlights. (HEX: #B8144D)
- Accent color: A vibrant fuchsia, providing a playful contrast and drawing attention to interactive elements, particularly the 'Yes' button. (HEX: #CC4CB2)
- The primary font for both headlines and body text will be 'Alegreya', a humanist serif, conveying an elegant, warm, and contemporary intellectual feel, perfect for a heartfelt message.
- A minimalist, centered layout will keep the focus on the proposal message and the interactive buttons, providing an uncluttered and emotional experience. The design should be fully responsive to ensure a seamless experience on any device.
- Subtle and smooth transitions for button resizing and fading effects will ensure a polished user experience. A vibrant confetti animation will mark the acceptance of the proposal.
